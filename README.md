# MEDIA CRE

BTL Representative Company · Outdoor Media Creative Power

## Stack

- Next.js App Router
- React
- TypeScript
- CSS design system
- Vercel deployment target

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run validate
npm run build
```

## Environment

Copy `.env.example` to `.env.local`.

Required before production:

- `NEXT_PUBLIC_SITE_URL`
- Optional `CONTACT_WEBHOOK_URL`

## Deployment state

Current branch: predeploy/v0.7

Vercel connection is intentionally pending final account/domain review.
